Layout: navigator on the left (Project, Source Control, Search, Issues…), editor in the middle, inspectors on the right, debug area at the bottom; toolbar on top with Run and Stop, the scheme and run-destination menu.

Stable shortcuts: Run ⌘R, Stop ⌘., Build ⌘B, Clean Build Folder ⇧⌘K, Open Quickly ⇧⌘O, Find in Project ⇧⌘F, show or hide the navigator ⌘0, inspectors ⌥⌘0, debug area ⇧⌘Y, comment a line ⌘/, jump to definition ⌃⌘J (or ⌘-click).

Pitfalls: signing errors live in the target's Signing & Capabilities tab; the run destination menu decides which Mac or device runs the app; SwiftUI previews need the canvas (⌥⌘↩).

Trust the screenshot when menus differ: Xcode moves things between versions.
