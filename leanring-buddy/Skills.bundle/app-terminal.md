Shortcuts: new tab ⌘T, new window ⌘N, clear ⌘K, interrupt a running command ⌃C, end of input ⌃D, search history ⌃R, start or end of line ⌃A or ⌃E, autocomplete Tab.

Helping well: say the command in words and what it does before the user runs it; for anything that deletes, overwrites, or uses sudo, explain the risk first. Prefer reading the visible error output on screen and quoting the key line.

Common needs: cd, ls -la, pwd, open . (Finder here), which or command -v, git status, brew install.
