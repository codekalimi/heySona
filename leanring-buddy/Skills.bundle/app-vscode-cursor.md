Layout: activity bar on the far left (Explorer, Search, Source Control, Run and Debug, Extensions), side bar next to it, editor in the middle, panel at the bottom (Terminal, Problems, Output), status bar at the bottom edge. Cursor adds an AI chat pane, usually on the right.

Stable shortcuts: Command Palette ⇧⌘P, Quick Open ⌘P, toggle terminal ⌃`, side bar ⌘B, find in files ⇧⌘F, go to definition F12, rename symbol F2, format document ⇧⌥F, multi-cursor ⌥-click, comment ⌘/. Cursor: inline edit ⌘K, chat ⌘L (check the screenshot).

Pitfalls: the interpreter or SDK picker is in the status bar or Command Palette; settings are in both a UI and settings.json.
